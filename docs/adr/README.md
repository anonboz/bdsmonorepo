# docs/adr

Architecture Decision Records. One file per decision that is hard to reverse or
expensive to revisit.

Naming: `NNNN-<kebab-title>.md` — e.g., `0001-payment-provider-for-vn.md`.

When an open decision in `BUILD_PLAN.md §8` is settled, move it to an ADR here
and tick the checkbox in `BUILD_PLAN.md`.
